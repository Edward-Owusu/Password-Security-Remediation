# Corporate Password Security & Clean Desk Policy

**Document Reference:** PL-SEC-005  
**Version:** 1.0

## 1. Purpose

Define requirements for securing credentials and reducing physical credential exposure.

## 2. Scope

Applies to organizational personnel, corporate facilities, remote workstations, and external workforce members using company infrastructure.

## 3. Mandatory Controls

### 3.1 Clean Desk & Clear Screen

Personnel must not leave clear-text credentials, password notes, whiteboards, or MFA backup materials visible or exposed.

### 3.2 Prohibited Physical and Unencrypted Storage

Recording authenticators on physical materials or in unencrypted local documents is prohibited. Corporate authentication information must be stored only in approved credential-management solutions.

### 3.3 Approved Authentication

Personnel must use organization-approved authentication mechanisms and follow identity and access-management requirements.

## 4. Enforcement

Exceptions may result in security retraining, access or privilege review, and progressive disciplinary action consistent with organizational policy.

## 5. Review

The policy should be reviewed periodically and after significant changes to authentication technology, regulatory requirements, or the organization's threat environment.
