# Remediation Plan

## Finding

Physical storage of passwords creates an avoidable credential-exposure risk.

## Remediation Actions

| Action | Priority | Owner | Success Measure |
|---|---|---|---|
| Deploy approved Enterprise Password Manager | High | IAM / Security | >98% active-user adoption |
| Identify users still storing credentials physically | High | GRC / Security | 100% identified exceptions tracked |
| Implement passwordless authentication for eligible users | Medium | IAM | Approved population enrolled |
| Conduct monthly clean-desk inspections | Medium | Physical Security / GRC | 0 exposed credentials |
| Deliver recurring security-hygiene training | Medium | Security Awareness / HR | 100% completion |

## Validation

GRC or Internal Audit should validate remediation using objective evidence before the finding is formally closed.

## Closure Criteria

A remediation item should not be considered closed solely because management reports completion. Closure should be supported by evidence demonstrating that the control operates as intended.
