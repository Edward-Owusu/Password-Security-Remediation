# Control Mapping

## Framework Mapping

| Risk / Control Area | ISO/IEC 27001:2022 | NIST SP 800-53 | SOC 2 |
|---|---|---|---|
| User endpoint security | A.8.1 | IA-5 | CC6.1 |
| Secure working areas | A.7.14 | PE-3 | CC6.3 |
| Credential/authenticator management | A.8.1 / applicable access controls | IA-5 | CC6.1 |
| Physical access | A.7.14 | PE-3 | CC6.3 |

## Proposed Control Set

### CTRL-001 – Enterprise Password Manager
Centralize credential storage in an approved password-management platform.

### CTRL-002 – Passwordless Authentication
Use FIDO2 or Windows Hello for Business for suitable user populations.

### CTRL-003 – Clean Desk & Clear Screen
Inspect workspaces for exposed credentials and other sensitive information.

### CTRL-004 – Security Awareness
Provide recurring training on password hygiene and secure authentication practices.

> These mappings are portfolio-level examples. Organizations should validate exact control applicability against their approved control framework, scope, and audit methodology.
