# Audit Testing Procedures

## AUD-003.1 – Clean Desk Inspection

**Objective:** Determine whether employees leave passwords or MFA backup materials exposed.

**Frequency:** Monthly

**Evidence:**
- Physical inspection logs
- Exception reports
- Compliance scorecards
- Incident records

**Target:** 0 exposed corporate passwords or MFA backup materials.

## AUD-003.2 – Password Manager Adoption

**Objective:** Evaluate adoption and operational use of the Enterprise Password Manager.

**Frequency:** Monthly

**Evidence:**
- EPM console exports
- License allocation reports
- Identity directory reports
- User adoption metrics

**Target:** >98% active corporate-user utilization.

## AUD-003.3 – Security Hygiene Training

**Objective:** Verify completion of required password and security-hygiene training.

**Frequency:** Quarterly

**Evidence:**
- LMS completion records
- Training certificates
- Escalation records

**Target:** 100% completion among active personnel.

## Audit Conclusion Approach

Test results should be documented as:

- Effective
- Partially Effective
- Ineffective
- Not Tested

Any exception should include the condition, criteria, cause, impact, recommendation, owner, and remediation target date.
